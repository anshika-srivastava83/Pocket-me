# Pocket-me
A secure, free, self-hosted personal AI assistant PWA with multi-space memory, file management, and model fallbacks.

A secure, fully self-hosted personal AI assistant PWA built for Android. It features multi-space memory, file extraction, automated reminders, and a smart model fallback switcher (Gemini, Groq, OpenRouter).

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, PWA Service Worker
- **Backend:** Node.js, Express
- **Database:** Supabase (PostgreSQL)
- **File Storage:** Google Drive API
